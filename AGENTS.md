# Grøn start – instruktioner til Codex

## Projekt
Grøn start er et statisk website udviklet som Tema 2-opgave på 1. semester af multimediedesignuddannelsen.

Websitet er bygget ud fra en eksisterende high fidelity Figma-prototype og består af fire sider:
- Forside
- Begynderguide
- Udstyr
- Første planteprojekt

## Arbejdsprincipper
- Læs eksisterende kode før ændringer.
- Bevar det eksisterende Figma-design.
- Redesign ikke løsningen.
- Foretag kun ændringer, der er nødvendige for den aktuelle opgave.
- Bevar fungerende kode.
- Brug semantisk HTML og struktureret CSS.
- Hold koden enkel og forståelig for en studerende på 1. semester.
- Brug ikke PHP, frameworks, database eller eksterne API'er.
- Brug kun JavaScript, hvis det er nødvendigt.
- Bevar responsivitet på desktop og mobil.
- Tag hensyn til tilgængelighed.
- Opfind ikke indhold eller designværdier, der ikke kan verificeres.

## Kontrol
Efter ændringer skal relevante sider kontrolleres for:
- fungerende interne links
- responsivitet
- vandret overflow
- navigation og mobilmenu
- relevante tilgængelighedsproblemer

Fortæl til sidst kort:
1. hvilke filer der er ændret
2. hvad der er ændret
3. hvad der er kontrolleret
4. om noget stadig kræver manuel kontrol
